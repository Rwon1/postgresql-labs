# Лекция 11 — Егоров Дмитрий, 16М-нф26

Откройте `report.md`: задания 1–5, фактические планы, замеры и выводы.

Повторный запуск в отдельной пустой учебной базе PostgreSQL 16 через psql:

```text
psql -X -v ON_ERROR_STOP=1 -h 127.0.0.1 -p 55438 -U course_user -d <имя_учебной_базы> -f lecture11_Egorov.sql > repeat.log
```

Параметры подключения замените на свои. SQL сам дважды загружает соседний `lecture_11_seed.sql`, проверяет повторяемость, выполняет по 3 замера каждой фазы и проверки `EXCEPT ALL`. Запускайте весь файл, не отдельные фрагменты: контрольные таблицы временные. Индексы этой работы пересоздаются; остальные учебные работы не нужны.

`plans/` — 30 исходных JSON-планов и их читаемая TXT-расшифровка из тех же выполнений. `results/measurements.csv` — все замеры; `nodes.csv` — показатели каждого узла; `*_before.csv` / `*_after.csv` — результаты; `equality.csv`, `result_hashes.csv` и `controls.json` — проверки. Новый запуск пишет планы и проверки в `repeat.log`; приложенные CSV/JSON относятся к измерению, указанному в отчёте.
